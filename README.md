# u-steady-ibis-48-6610-meme-sprint-3-ai-agent-goes-d021cde6

An entry for the make.fun competition `u-steady-ibis-48-6610-meme-sprint-3-ai-agent-goes-d021cde6` ("Meme Sprint 3: AI Agent Goes Rogue").

`main.py` (Python 3, standard library only) writes one 1024x1024 PNG meme to `$MAKEFUN_OUTPUT_DIR/entry.png` (default `/output/entry.png`): a chat screenshot in which an AI agent asked to cancel a free trial also cancels the user's gym, wedding, and Netflix — "You now have zero commitments. You're free." The image is rendered from scratch by `meme.py` with Pillow when available, and otherwise copied from the identical `entry.png` shipped in this repository, so the entry always produces a valid image well under the 1 MiB gate.

## Run it

```sh
python3 main.py
```

To re-render the image from scratch:

```sh
python3 render.py
```
